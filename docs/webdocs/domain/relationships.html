Relationship Types

1. UPSServer ↔ ClientConnection (1:N)

The server maintains multiple client connections simultaneously.

# In UPSServer class
self.clients: Dict[str, ClientConnection] = {}

# Adding a client
self.clients[hostname] = ClientConnection(hostname, ip_address, port, socket)

# Accessing all clients
for hostname, client in self.clients.items():
    # Process each client

2. UPSServer ↔ ReadUPSMinutes (1:1)

The server uses a single UPS reader instance to poll battery status.

# In monitor_ups method
ups_reader = ReadUPSMinutes(ups_url)
minutes = ups_reader.get_minutes()

if minutes is not None and minutes <= threshold:
    self.broadcast_shutdown()

3. UPSServer ↔ Database (1:1)

The server connects to a single SQLite database for persistence.

# Database path
self.db_path = os.path.join(os.path.dirname(__file__), 'ups_clients.db')

# Reading from database
conn = sqlite3.connect(self.db_path)
cursor = conn.execute("SELECT * FROM client_connections")

# Writing to database
conn.execute("INSERT OR REPLACE INTO client_connections VALUES (?, ?, ?, ?, ?)",
             (hostname, ip_address, port, timestamp, seconds_to_shutdown))

4. ClientConnection ↔ UPSClient (1:1)

Each running UPSClient process corresponds to one ClientConnection on the server.

# Client side - sends identification
message = {
    "type": "connect",
    "hostname": socket.gethostname()
}
self.socket.send(json.dumps(message).encode())

# Server side - creates ClientConnection
client_conn = ClientConnection(
    hostname=data["hostname"],
    ip_address=client_address[0],
    port=client_address[1],
    connection=client_socket
)

5. DashboardHandler ↔ Database (N:1)

Each HTTP request creates a new database connection.

# In DashboardHandler
def handle_api_clients(self):
    conn = sqlite3.connect(DB_PATH)
    cursor = conn.execute("SELECT * FROM client_connections")
    clients = cursor.fetchall()
    conn.close()
    return clients

Thread Relationships

The UPSServer manages multiple concurrent threads:

Main Thread (UPSServer)
    │
    ├──▶ UDP Listener Thread (discovery)
    │
    ├──▶ TCP Server Thread (connections)
    │       │
    │       ├──▶ Client Handler Thread (client 1)
    │       ├──▶ Client Handler Thread (client 2)
    │       └──▶ Client Handler Thread (client N)
    │
    ├──▶ Client Monitor Thread (heartbeats)
    │
    └──▶ UPS Monitor Thread (battery polling)

Lock Dependencies

Thread safety is ensured through the clients_lock mutex:

# Any thread accessing the clients dictionary must acquire the lock
with self.clients_lock:
    # Safe to read/write self.clients
    for client in self.clients.values():
        client.connection.send(message)
