Business Rules

This document describes the core business rules and operational logic of the Riello UPS Servers Shutdown system.

Shutdown Rules

Rule 1: Battery Threshold Trigger

When: UPS battery autonomy drops to or below the configured threshold.

Then: Initiate shutdown sequence for all connected clients.

# Implementation in monitor_ups()
if minutes <= self.minimum_minutes and not self.shutdown_triggered:
    self.shutdown_triggered = True
    self.broadcast_shutdown()

Rule 2: Single Shutdown Execution

Constraint: Shutdown sequence executes only once per power event.

Rationale: Prevents repeated shutdown attempts if battery recovers then drops again.

# Flag prevents re-triggering
self.shutdown_triggered = False  # Reset only on server restart

Rule 3: Staggered Shutdown

Implementation: Each client has a configurable shutdown delay.

Default: 0 seconds (immediate shutdown).

Purpose: Allows graceful service dependency shutdown.

# Sending shutdown with delay
shutdown_message = {
    "type": "shutdown",
    "delay": client.seconds_to_shutdown
}
client.connection.send(json.dumps(shutdown_message).encode())

Rule 4: Server Shuts Down Last

Calculation: Server delay = Maximum client delay + 30 seconds buffer.

Rationale: Ensures server coordinates all client shutdowns before self-termination.

# Calculate server shutdown delay
max_client_delay = max(c.seconds_to_shutdown for c in self.clients.values())
server_delay = max_client_delay + 30  # 30 second buffer

# Schedule server shutdown
threading.Timer(server_delay, self.shutdown_server).start()

Connection Rules

Rule 5: Heartbeat Timeout

Interval: Clients send heartbeats every 30-60 seconds (randomized).

Timeout: 90 seconds without heartbeat marks client as disconnected.

Action: Remove client from active connections list.

# Client monitor thread
HEARTBEAT_TIMEOUT = 90  # seconds

for hostname, client in list(self.clients.items()):
    if time.time() - client.last_heartbeat > HEARTBEAT_TIMEOUT:
        logging.info(f"Client {hostname} timed out")
        self.remove_client(hostname)

Rule 6: Auto-Reconnection

Behavior: Clients automatically attempt reconnection on disconnect.

Backoff: Exponential backoff from 10 to 60 seconds.

Discovery: Re-runs server discovery if IP changes.

# Client reconnection logic
def run(self):
    retry_delay = 10
    while self.running:
        try:
            self.discover_server()
            self.connect()
            self.run_connected()
        except Exception:
            time.sleep(retry_delay)
            retry_delay = min(retry_delay * 2, 60)  # Max 60 seconds

Rule 7: Hostname Uniqueness

Constraint: Each hostname can have only one active connection.

Behavior: New connection replaces existing connection for same hostname.

Persistence: Shutdown delay setting preserved across reconnections.

# Hostname as unique identifier
self.clients[hostname] = new_client_connection

# Shutdown delay restored from database
stored_delay = self.get_stored_shutdown_delay(hostname)
new_client_connection.seconds_to_shutdown = stored_delay

UPS Polling Rules

Rule 8: Polling Interval

Interval: UPS status checked every 60 seconds.

Rationale: Balances responsiveness with network/API load.

UPS_POLL_INTERVAL = 60  # seconds

def monitor_ups(self):
    while self.running:
        minutes = self.ups_reader.get_minutes()
        self.current_ups_minutes = minutes
        time.sleep(UPS_POLL_INTERVAL)

Rule 9: API Failure Handling

Timeout: UPS API requests timeout after 10 seconds.

On Failure: Log error and continue polling; do not trigger shutdown.

Rationale: Transient network issues should not cause unnecessary shutdowns.

# Safe failure handling
try:
    response = urllib.request.urlopen(req, timeout=10, context=ctx)
    minutes = json.loads(response.read())['autonomy']
except Exception as e:
    logging.error(f"UPS API error: {e}")
    minutes = None  # Don't trigger shutdown on API failure

Configuration Rules

Rule 10: Default Configuration

UPS_URL: Must be configured before monitoring works.

UPS_minimum_minutes: Defaults to 15 minutes if not set.

Rule 11: Runtime Configuration

Behavior: Configuration changes via dashboard take effect immediately.

Persistence: Changes stored in database, survive restarts.

No Restart Required: Server reads config from database each poll cycle.

# Configuration read on each poll
def monitor_ups(self):
    while self.running:
        config = self.load_config_from_db()
        ups_url = config.get('UPS_URL')

Status Broadcasting Rules

Rule 12: Status Updates

Trigger: After each successful UPS poll.

Content: Current battery minutes sent to all connected clients.

Purpose: Allows clients to display/log UPS status.

# Broadcast status to all clients
status_message = {
    "type": "ups_status",
    "minutes": minutes
}

with self.clients_lock:
    for client in self.clients.values():
        try:
            client.connection.send(json.dumps(status_message).encode())
        except:
            pass  # Handle in heartbeat timeout

Platform-Specific Rules

Rule 13: OS-Specific Shutdown Commands

Linux/macOS: shutdown -h now

Windows: shutdown /s /t 0 /f

def execute_shutdown(self, delay: int):
    time.sleep(delay)
    
    system = platform.system().lower()
    if system == 'windows':
        subprocess.run(['shutdown', '/s', '/t', '0', '/f'], check=True)
    else:  # Linux, Darwin (macOS)
        subprocess.run(['shutdown', '-h', 'now'], check=True)
