Use Cases

This document provides detailed use cases with code examples for common scenarios in the Riello UPS Servers Shutdown system.

Use Case 1: Basic Server Deployment

Scenario: Deploy the UPS server on a Linux machine that should shut down last during power outages.

Implementation

#!/bin/bash
# deploy_server.sh - Complete server deployment script

set -e  # Exit on error

echo "Creating directories..."
sudo mkdir -p /opt/UPSserver

echo "Copying files..."
sudo cp UPSserver.py /opt/UPSserver/
sudo cp UPSdashboard.py /opt/UPSserver/

echo "Installing systemd services..."
sudo cp UPSserver.service /etc/systemd/system/
sudo cp UPSdashboard.service /etc/systemd/system/

echo "Setting up log rotation..."
sudo cp UPSserver.logrotate /etc/logrotate.d/UPSserver
sudo cp UPSdashboard.logrotate /etc/logrotate.d/UPSdashboard

echo "Starting services..."
sudo systemctl daemon-reload
sudo systemctl enable UPSserver UPSdashboard
sudo systemctl start UPSserver UPSdashboard

echo "Deployment complete!"
echo "Configure via dashboard: http://$(hostname -I | awk '{print $1}'):8080"

Verification

# Verify server is running
systemctl status UPSserver

# Check logs for startup
tail -20 /var/log/UPSserver.log

Use Case 2: Multi-Client Deployment

Scenario: Deploy the UPS client to multiple machines using a script.

Implementation

#!/bin/bash
# deploy_client.sh - Deploy client to remote machines

MACHINES="web-01 web-02 db-01 app-01"
SOURCE_DIR="/path/to/client"

for machine in $MACHINES; do
    echo "Deploying to $machine..."
    
    # Create directory
    ssh root@$machine "mkdir -p /opt/UPSclient"
    
    # Copy files
    scp $SOURCE_DIR/UPSclient.py root@$machine:/opt/UPSclient/
    scp $SOURCE_DIR/UPSclient.service root@$machine:/etc/systemd/system/
    scp $SOURCE_DIR/UPSclient.logrotate root@$machine:/etc/logrotate.d/UPSclient
    
    # Start service
    ssh root@$machine "systemctl daemon-reload && systemctl enable UPSclient && systemctl start UPSclient"
    
    echo "$machine: Done"
done

echo "All deployments complete!"

Use Case 3: Configure Staggered Shutdown

Scenario: Configure a three-tier application with proper shutdown order:

  • Web servers shut down first (0 seconds)
  • Application servers shut down after 30 seconds
  • Database server shuts down after 60 seconds

Implementation via Dashboard

  1. Open http://server-ip:8080
  2. Set shutdown delays for each client

Implementation via API

#!/bin/bash
# configure_shutdown_delays.sh

SERVER="http://192.168.1.10:8080"

# Configure web servers (immediate shutdown)
curl -X POST "$SERVER/api/update_shutdown" \
    -d "hostname=web-server-01&seconds=0"
curl -X POST "$SERVER/api/update_shutdown" \
    -d "hostname=web-server-02&seconds=0"

# Configure app server (30 second delay)
curl -X POST "$SERVER/api/update_shutdown" \
    -d "hostname=app-server-01&seconds=30"

# Configure database server (60 second delay)
curl -X POST "$SERVER/api/update_shutdown" \
    -d "hostname=db-server-01&seconds=60"

echo "Shutdown delays configured!"

Verification

# Verify configuration
curl http://192.168.1.10:8080/api/clients | python3 -m json.tool

Use Case 4: Monitor UPS Status via API

Scenario: Create a monitoring script that checks UPS status and sends alerts.

Implementation

#!/usr/bin/env python3
"""UPS monitoring script with email alerts."""

import urllib.request
import json
import smtplib
from email.mime.text import MIMEText

DASHBOARD_URL = "http://192.168.1.10:8080"
ALERT_EMAIL = "admin@example.com"
SMTP_SERVER = "smtp.example.com"
WARNING_THRESHOLD = 30  # minutes

def get_ups_status():
    """Fetch current UPS status from dashboard API."""
    url = f"{DASHBOARD_URL}/api/ups_status"
    with urllib.request.urlopen(url, timeout=10) as response:
        return json.loads(response.read().decode())

def send_alert(subject: str, message: str):
    """Send email alert."""
    msg = MIMEText(message)
    msg['Subject'] = subject
    msg['From'] = 'ups-monitor@example.com'
    msg['To'] = ALERT_EMAIL
    
    with smtplib.SMTP(SMTP_SERVER) as server:
        server.send_message(msg)

def main():
    status = get_ups_status()
    minutes = status.get('minutes')
    
    if minutes is None:
        send_alert(
            "UPS Alert: Status Unknown",
            "Cannot retrieve UPS battery status. Check server logs."
        )
    elif minutes <= WARNING_THRESHOLD:
        send_alert(
            f"UPS Alert: Low Battery ({minutes} minutes)",
            f"UPS battery is low: {minutes} minutes remaining.\n"
            f"Threshold for shutdown: {status.get('threshold')} minutes.\n"
            f"Status: {status.get('status')}"
        )
        print(f"Alert sent: {minutes} minutes remaining")
    else:
        print(f"UPS OK: {minutes} minutes remaining")

if __name__ == "__main__":
    main()

Use Case 5: Dashboard Behind Reverse Proxy

Scenario: Secure dashboard access with HTTPS and basic authentication using nginx.

Nginx Configuration

# /etc/nginx/sites-available/ups-dashboard
server {
    listen 443 ssl;
    server_name ups.example.com;
    
    ssl_certificate /etc/ssl/certs/ups.crt;
    ssl_certificate_key /etc/ssl/private/ups.key;
    
    # Basic authentication
    auth_basic "UPS Dashboard";
    auth_basic_user_file /etc/nginx/.htpasswd;
    
    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

# Redirect HTTP to HTTPS
server {
    listen 80;
    server_name ups.example.com;
    return 301 https://$server_name$request_uri;
}

Create Password File

# Install apache2-utils for htpasswd
sudo apt-get install apache2-utils

# Create password file
sudo htpasswd -c /etc/nginx/.htpasswd admin

# Enable site
sudo ln -s /etc/nginx/sites-available/ups-dashboard /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

Use Case 6: Custom Shutdown Scripts

Scenario: Execute custom cleanup scripts before shutdown on a client machine.

Modified Client

# Modified execute_shutdown method in UPSclient.py

def execute_shutdown(self, delay: int):
    """Execute pre-shutdown scripts and then shutdown."""
    logging.info(f"Shutdown in {delay} seconds")
    time.sleep(delay)
    
    # Run custom pre-shutdown scripts
    pre_shutdown_scripts = [
        '/opt/scripts/stop_services.sh',
        '/opt/scripts/backup_database.sh',
        '/opt/scripts/notify_team.sh'
    ]
    
    for script in pre_shutdown_scripts:
        if os.path.exists(script):
            logging.info(f"Running pre-shutdown script: {script}")
            try:
                subprocess.run([script], timeout=60, check=True)
            except subprocess.TimeoutExpired:
                logging.warning(f"Script timed out: {script}")
            except subprocess.CalledProcessError as e:
                logging.error(f"Script failed: {script} - {e}")
    
    # Execute system shutdown
    logging.info("Executing system shutdown")
    system = platform.system().lower()
    if system == 'windows':
        subprocess.run(['shutdown', '/s', '/t', '0', '/f'], check=True)
    else:
        subprocess.run(['shutdown', '-h', 'now'], check=True)

Use Case 7: Health Check Endpoint

Scenario: Create a health check script for monitoring systems.

Implementation

#!/usr/bin/env python3
"""Health check script for load balancers/monitoring."""

import urllib.request
import json
import sys

DASHBOARD_URL = "http://localhost:8080"

def health_check():
    """Check system health and return appropriate exit code."""
    try:
        # Check dashboard is responding
        url = f"{DASHBOARD_URL}/api/ups_status"
        with urllib.request.urlopen(url, timeout=5) as response:
            data = json.loads(response.read().decode())
        
        # Check UPS status
        status = data.get('status', 'unknown')
        minutes = data.get('minutes')
        
        if status == 'critical':
            print(f"CRITICAL: UPS battery critical ({minutes} minutes)")
            return 2
        elif status == 'warning':
            print(f"WARNING: UPS battery low ({minutes} minutes)")
            return 1
        elif status == 'ok':
            print(f"OK: UPS battery good ({minutes} minutes)")
            return 0
        else:
            print(f"UNKNOWN: Cannot determine UPS status")
            return 3
            
    except Exception as e:
        print(f"CRITICAL: Cannot reach dashboard - {e}")
        return 2

if __name__ == "__main__":
    sys.exit(health_check())

Use Case 8: Client Status Report

Scenario: Generate a daily report of connected clients and UPS status.

Implementation

#!/usr/bin/env python3
"""Generate daily UPS client status report."""

import urllib.request
import json
from datetime import datetime

DASHBOARD_URL = "http://192.168.1.10:8080"

def generate_report():
    """Generate status report."""
    # Fetch data
    with urllib.request.urlopen(f"{DASHBOARD_URL}/api/clients") as r:
        clients_data = json.loads(r.read().decode())
    
    with urllib.request.urlopen(f"{DASHBOARD_URL}/api/ups_status") as r:
        ups_data = json.loads(r.read().decode())
    
    with urllib.request.urlopen(f"{DASHBOARD_URL}/api/config") as r:
        config_data = json.loads(r.read().decode())
    
    # Generate report
    report = []
    report.append("=" * 60)
    report.append(f"UPS STATUS REPORT - {datetime.now().strftime('%Y-%m-%d %H:%M')}")
    report.append("=" * 60)
    report.append("")
    
    # UPS Status
    report.append("UPS STATUS:")
    report.append(f"  Battery: {ups_data.get('minutes', 'Unknown')} minutes")
    report.append(f"  Threshold: {ups_data.get('threshold')} minutes")
    report.append(f"  Status: {ups_data.get('status', 'Unknown').upper()}")
    report.append("")
    
    # Configuration
    report.append("CONFIGURATION:")
    report.append(f"  UPS URL: {config_data.get('UPS_URL', 'Not configured')}")
    report.append(f"  Minimum Minutes: {config_data.get('UPS_minimum_minutes', '15')}")
    report.append("")
    
    # Client List
    report.append("CONNECTED CLIENTS:")
    report.append("-" * 60)
    report.append(f"{'Hostname':<20} {'IP Address':<15} {'Delay':>8} {'Last Seen':<20}")
    report.append("-" * 60)
    
    for client in clients_data.get('clients', []):
        report.append(
            f"{client['hostname']:<20} "
            f"{client['ip_address']:<15} "
            f"{client['seconds_to_shutdown']:>6}s  "
            f"{client['last_connection_time']:<20}"
        )
    
    report.append("-" * 60)
    report.append(f"Total clients: {len(clients_data.get('clients', []))}")
    report.append("")
    
    return "\n".join(report)

if __name__ == "__main__":
    print(generate_report())

Use Case 9: Database Backup Before Shutdown

Scenario: Automatically backup database when shutdown is triggered.

Pre-Shutdown Backup Script

#!/bin/bash
# /opt/scripts/backup_database.sh

BACKUP_DIR="/backup/emergency"
TIMESTAMP=$(date +%Y%m%d_%H%M%S)

# Create backup directory
mkdir -p $BACKUP_DIR

# PostgreSQL backup
if command -v pg_dump &> /dev/null; then
    echo "Backing up PostgreSQL..."
    pg_dump -U postgres mydb > "$BACKUP_DIR/postgres_$TIMESTAMP.sql"
fi

# MySQL backup
if command -v mysqldump &> /dev/null; then
    echo "Backing up MySQL..."
    mysqldump -u root --all-databases > "$BACKUP_DIR/mysql_$TIMESTAMP.sql"
fi

# Compress backups
gzip $BACKUP_DIR/*.sql 2>/dev/null

echo "Emergency backup completed: $BACKUP_DIR"

Use Case 10: Integration with Slack Notifications

Scenario: Send Slack notifications when shutdown is triggered.

Implementation

#!/usr/bin/env python3
"""Slack notification for UPS events."""

import urllib.request
import json

SLACK_WEBHOOK = "https://hooks.slack.com/services/YOUR/WEBHOOK/URL"

def send_slack_notification(message: str, channel: str = "#ops-alerts"):
    """Send notification to Slack."""
    payload = {
        "channel": channel,
        "username": "UPS Monitor",
        "icon_emoji": ":electric_plug:",
        "text": message
    }
    
    data = json.dumps(payload).encode('utf-8')
    req = urllib.request.Request(
        SLACK_WEBHOOK,
        data=data,
        headers={'Content-Type': 'application/json'}
    )
    
    urllib.request.urlopen(req)

# Example: Call from pre-shutdown script
def notify_shutdown(hostname: str, delay: int, battery_minutes: int):
    """Notify team about impending shutdown."""
    message = (
        f":warning: *UPS SHUTDOWN ALERT*\n"
        f"• Host: `{hostname}`\n"
        f"• Shutdown in: {delay} seconds\n"
        f"• Battery remaining: {battery_minutes} minutes\n"
        f"• Time: {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}"
    )
    send_slack_notification(message)

if __name__ == "__main__":
    import sys
    from datetime import datetime
    
    if len(sys.argv) >= 4:
        notify_shutdown(sys.argv[1], int(sys.argv[2]), int(sys.argv[3]))
