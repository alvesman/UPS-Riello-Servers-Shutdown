Service Reference

This document provides detailed reference information for all systemd services in the Riello UPS Servers Shutdown system.

Service Overview

ServicePurposeDeploy On
UPSserver.serviceCore UPS monitoring and client coordinationMain server (shuts down last)
UPSdashboard.serviceWeb management interfaceSame machine as UPSserver
UPSclient.serviceClient shutdown agentAll other machines

UPSserver.service

Location: /etc/systemd/system/UPSserver.service

Source: server/UPSserver.service

Service File

[Unit]
Description=UPS Server for graceful shutdown coordination
After=network.target

[Service]
Type=simple
User=root
Group=root
WorkingDirectory=/opt/UPSserver
ExecStart=/usr/bin/python3 /opt/UPSserver/UPSserver.py
Restart=always
RestartSec=5
StandardOutput=append:/var/log/UPSserver.log
StandardError=append:/var/log/UPSserver_error.log

[Install]
WantedBy=multi-user.target

Configuration Details

DirectiveValueDescription
Afternetwork.targetStarts after network is available
TypesimpleMain process is the service
User/GrouprootRequired for shutdown command
WorkingDirectory/opt/UPSserverDatabase created here
RestartalwaysRestart on any exit
RestartSec5Wait 5s before restart

Management Commands

# Start the service
sudo systemctl start UPSserver

# Stop the service
sudo systemctl stop UPSserver

# Restart the service
sudo systemctl restart UPSserver

# Check status
sudo systemctl status UPSserver

# Enable auto-start on boot
sudo systemctl enable UPSserver

# View logs
sudo journalctl -u UPSserver -f
sudo tail -f /var/log/UPSserver.log

Command-Line Arguments

The dashboard accepts an optional port argument:

# Default port (8080)
ExecStart=/usr/bin/python3 /opt/UPSserver/UPSdashboard.py

# Custom port
ExecStart=/usr/bin/python3 /opt/UPSserver/UPSdashboard.py 9090

Log Rotation

Each service has an associated logrotate configuration.

UPSserver.logrotate

/var/log/UPSserver.log /var/log/UPSserver_error.log {
    daily
    rotate 7
    compress
    delaycompress
    missingok
    notifempty
    create 640 root root
    size 10M
    postrotate
        systemctl reload UPSserver > /dev/null 2>&1 || true
    endscript
}

Installation

# Copy logrotate configs
sudo cp server/UPSserver.logrotate /etc/logrotate.d/UPSserver
sudo cp server/UPSdashboard.logrotate /etc/logrotate.d/UPSdashboard
sudo cp client/UPSclient.logrotate /etc/logrotate.d/UPSclient

# Test configuration
sudo logrotate -d /etc/logrotate.d/UPSserver

Rotation Settings

SettingValueDescription
daily-Rotate daily
rotate7Keep 7 rotated files
compress-Compress rotated logs with gzip
size10MAlso rotate if size exceeds 10MB

Installation Script

Complete installation commands for server:

#!/bin/bash
# Server installation script

# Create directories
sudo mkdir -p /opt/UPSserver

# Copy files
sudo cp server/UPSserver.py /opt/UPSserver/
sudo cp server/UPSdashboard.py /opt/UPSserver/

# Install systemd services
sudo cp server/UPSserver.service /etc/systemd/system/
sudo cp server/UPSdashboard.service /etc/systemd/system/

# Install logrotate configs
sudo cp server/UPSserver.logrotate /etc/logrotate.d/UPSserver
sudo cp server/UPSdashboard.logrotate /etc/logrotate.d/UPSdashboard

# Reload systemd
sudo systemctl daemon-reload

# Enable and start services
sudo systemctl enable UPSserver UPSdashboard
sudo systemctl start UPSserver UPSdashboard

# Verify status
sudo systemctl status UPSserver UPSdashboard

Troubleshooting

Service Won't Start

# Check for errors
sudo journalctl -u UPSserver -n 50 --no-pager

# Check file permissions
ls -la /opt/UPSserver/
ls -la /var/log/UPSserver.log

# Check port availability
sudo ss -tlnp | grep 5226

Service Keeps Restarting

# Check error log
sudo tail -100 /var/log/UPSserver_error.log

# Check Python version
python3 --version

# Test script manually
sudo python3 /opt/UPSserver/UPSserver.py
