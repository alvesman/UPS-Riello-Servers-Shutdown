API Endpoints

This document details all HTTP API endpoints provided by the UPS Dashboard server.

Base URL

http://<server-ip>:8080

GET Endpoints

GET /

Returns the HTML dashboard page.

MethodGET
Response Typetext/html
DescriptionMain dashboard interface with client list, UPS status, and configuration

Example Request:

curl http://localhost:8080/

GET /api/clients

Returns all connected clients and their status.

MethodGET
Response Typeapplication/json

Example Request:

curl http://localhost:8080/api/clients

Response Body:

{
  "clients": [
    {
      "hostname": "web-server-01",
      "ip_address": "192.168.1.100",
      "port": 5226,
      "last_connection_time": "2024-01-15T10:30:00",
      "seconds_to_shutdown": 0
    },
    {
      "hostname": "db-server-01",
      "ip_address": "192.168.1.101",
      "port": 5226,
      "last_connection_time": "2024-01-15T10:29:45",
      "seconds_to_shutdown": 30
    }
  ]
}

Response Fields:

FieldTypeDescription
hostnamestringClient machine hostname
ip_addressstringClient IP address
portintegerConnection port
last_connection_timestringISO 8601 timestamp
seconds_to_shutdownintegerShutdown delay in seconds

GET /api/config

Returns current server configuration.

MethodGET
Response Typeapplication/json

Example Request:

curl http://localhost:8080/api/config

Response Body:

{
  "UPS_URL": "https://192.168.1.1/json/live_data.json",
  "UPS_minimum_minutes": "15"
}

Response Fields:

FieldTypeDescription
UPS_URLstringFull URL to UPS JSON API endpoint
UPS_minimum_minutesstringBattery threshold in minutes

GET /api/ups_status

Returns current UPS battery status.

MethodGET
Response Typeapplication/json

Example Request:

curl http://localhost:8080/api/ups_status

Response Body:

{
  "minutes": 120,
  "threshold": 15,
  "status": "ok"
}

Response Fields:

FieldTypeDescription
minutesinteger|nullCurrent battery autonomy in minutes
thresholdintegerConfigured shutdown threshold
statusstring"ok", "warning", "critical", or "unknown"

POST Endpoints

POST /api/update_shutdown

Updates the shutdown delay for a specific client.

MethodPOST
Content Typeapplication/x-www-form-urlencoded
Response Typeapplication/json

Request Parameters:

ParameterTypeRequiredDescription
hostnamestringYesClient hostname to update
secondsintegerYesNew shutdown delay (≥ 0)

Example Request:

curl -X POST http://localhost:8080/api/update_shutdown \
  -d "hostname=web-server-01&seconds=60"

Success Response:

{
  "success": true,
  "message": "Updated shutdown delay for web-server-01 to 60 seconds"
}

Error Response:

{
  "success": false,
  "error": "Client not found"
}

POST /api/update_config

Updates server configuration (UPS URL and threshold).

MethodPOST
Content Typeapplication/x-www-form-urlencoded
Response Typeapplication/json

Request Parameters:

ParameterTypeRequiredDescription
ups_urlstringYesFull URL to UPS JSON API
minimum_minutesintegerYesBattery threshold (> 0)

Example Request:

curl -X POST http://localhost:8080/api/update_config \
  -d "ups_url=https://192.168.1.1/json/live_data.json&minimum_minutes=20"

Success Response:

{
  "success": true,
  "message": "Configuration updated"
}

TCP Protocol (Server-Client)

Discovery Protocol (UDP)

Port5225
ProtocolUDP Broadcast

Client Discovery Request:

UPS_DISCOVER

Server Discovery Response:

UPS_SERVER

Connection Protocol (TCP)

Port5226
ProtocolTCP
FormatJSON messages, newline-delimited

Message Types

connect - Client → Server (initial connection):

{
  "type": "connect",
  "hostname": "web-server-01"
}

heartbeat - Client → Server (periodic):

{
  "type": "heartbeat",
  "hostname": "web-server-01"
}

ups_status - Server → Client (broadcast):

{
  "type": "ups_status",
  "minutes": 120
}

shutdown - Server → Client (shutdown command):

{
  "type": "shutdown",
  "delay": 30
}
