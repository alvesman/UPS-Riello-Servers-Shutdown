Database Schema

This document describes the SQLite database schema used by the Riello UPS Servers Shutdown system.

Overview

Database EngineSQLite 3
File Location/opt/UPSserver/ups_clients.db
Tables2 (client_connections, configuration)
CreationAutomatic on first server start

Entity-Relationship Diagram

│         client_connections          │
├─────────────────────────────────────┤
│ PK hostname          TEXT NOT NULL  │
│    ip_address        TEXT           │
│    port              INTEGER        │
│    last_connection_time TEXT        │
│    seconds_to_shutdown INTEGER      │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│           configuration             │
├─────────────────────────────────────┤

│    value             TEXT           │
└─────────────────────────────────────┘
Note: Tables are independent with no foreign key relationships.

client_connections Table

Stores information about connected client machines.

Schema Definition

CREATE TABLE IF NOT EXISTS client_connections (
    hostname TEXT PRIMARY KEY,
    ip_address TEXT,
    port INTEGER,
    last_connection_time TEXT,
    seconds_to_shutdown INTEGER DEFAULT 0
);

Column Descriptions

ColumnTypeConstraintsDescription
hostname TEXT PRIMARY KEY, NOT NULL Unique client hostname identifier
ip_address TEXT - Client's IPv4 address (e.g., "192.168.1.100")
port INTEGER - TCP connection port number
last_connection_time TEXT - ISO 8601 timestamp of last connection/heartbeat
seconds_to_shutdown INTEGER DEFAULT 0 Shutdown delay in seconds (0 = immediate)

Example Data

SELECT * FROM client_connections;

-- hostname         | ip_address     | port | last_connection_time    | seconds_to_shutdown
-- -----------------+----------------+------+-------------------------+--------------------
-- web-server-01    | 192.168.1.100  | 5226 | 2024-01-15T10:30:00     | 0
-- db-server-01     | 192.168.1.101  | 5226 | 2024-01-15T10:29:45     | 30
-- app-server-01    | 192.168.1.102  | 5226 | 2024-01-15T10:28:00     | 60

configuration Table

Stores system configuration key-value pairs.

Schema Definition

CREATE TABLE IF NOT EXISTS configuration (
    key TEXT PRIMARY KEY,
    value TEXT
);

Column Descriptions

ColumnTypeConstraintsDescription
key TEXT PRIMARY KEY, NOT NULL Configuration key name
value TEXT - Configuration value (stored as string)

Standard Configuration Keys

KeyExample ValueDescription
UPS_URL https://192.168.1.1/json/live_data.json Full URL to Riello UPS JSON API endpoint
UPS_minimum_minutes 15 Battery threshold to trigger shutdown

Example Data

SELECT * FROM configuration;

-- key                  | value
-- ---------------------+------------------------------------------
-- UPS_URL              | https://192.168.1.1/json/live_data.json
-- UPS_minimum_minutes  | 15

Database Initialization

The database is created automatically when the server starts:

def init_database(self):
    """Initialize the SQLite database with required tables."""
    conn = sqlite3.connect(self.db_path)
    cursor = conn.cursor()
    
    # Create client_connections table
    cursor.execute('''
        CREATE TABLE IF NOT EXISTS client_connections (
            hostname TEXT PRIMARY KEY,
            ip_address TEXT,
            port INTEGER,
            last_connection_time TEXT,
            seconds_to_shutdown INTEGER DEFAULT 0
        )
    ''')
    
    # Create configuration table
    cursor.execute('''
        CREATE TABLE IF NOT EXISTS configuration (
            key TEXT PRIMARY KEY,
            value TEXT
        )
    ''')
    
    conn.commit()
    conn.close()

Database Operations

Insert/Update Client

INSERT OR REPLACE INTO client_connections 
    (hostname, ip_address, port, last_connection_time, seconds_to_shutdown)
VALUES 
    ('web-server-01', '192.168.1.100', 5226, '2024-01-15T10:30:00', 0);

Update Heartbeat Time

UPDATE client_connections 
SET last_connection_time = '2024-01-15T10:31:00'
WHERE hostname = 'web-server-01';

Update Shutdown Delay

UPDATE client_connections 
SET seconds_to_shutdown = 60
WHERE hostname = 'web-server-01';

Get All Clients

SELECT hostname, ip_address, port, last_connection_time, seconds_to_shutdown
FROM client_connections
ORDER BY hostname;

Get Configuration

SELECT key, value FROM configuration;

Update Configuration

INSERT OR REPLACE INTO configuration (key, value)
VALUES ('UPS_minimum_minutes', '20');

Database Maintenance

Backup

# Create backup
cp /opt/UPSserver/ups_clients.db /opt/UPSserver/ups_clients.db.backup

# Backup with date
cp /opt/UPSserver/ups_clients.db "/opt/UPSserver/ups_clients_$(date +%Y%m%d).db"

Reset Database

# Stop services
sudo systemctl stop UPSserver UPSdashboard

# Remove database (will be recreated on restart)
rm /opt/UPSserver/ups_clients.db

# Restart services
sudo systemctl start UPSserver UPSdashboard

View Database Contents

# Using sqlite3 CLI
sqlite3 /opt/UPSserver/ups_clients.db

# View all tables
.tables

# View clients
SELECT * FROM client_connections;

# View config
SELECT * FROM configuration;

# Exit
.quit

Data Integrity

Constraints

  • hostname is PRIMARY KEY - ensures unique clients
  • key is PRIMARY KEY - ensures unique config keys
  • seconds_to_shutdown defaults to 0 if not specified

Concurrency

SQLite handles concurrency automatically. The application uses:

  • Short-lived connections (open, execute, close)
  • No explicit transaction management
  • Default SQLite locking behavior
